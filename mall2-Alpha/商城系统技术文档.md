# 商城系统技术文档

## 1. 项目简介

本商城系统是一个基于前后端分离架构的电商平台，提供用户登录注册、商品浏览、购物车管理、订单管理等核心功能。系统采用Spring Boot作为后端框架，Vue 3作为前端框架，实现了完整的电商业务流程。

## 4. 功能特性

### 4.1 用户模块

- **登录**：支持用户名和密码登录
- **注册**：支持用户名、密码、手机号码注册，包含短信验证码验证
- **忘记密码**：支持通过手机号码和验证码重置密码
- **密码规则**：密码必须包含大小写字母、数字和特殊字符，长度至少8位
- **密码可见性**：注册和登录时支持密码可见性切换
- **密码确认**：注册时需要输入两次密码进行确认

### 4.2 商品模块

- **商品列表**：展示所有商品，支持分页
- **商品详情**：展示商品的详细信息
- **商品分类**：支持按分类查看商品
- **热门商品**：展示热门商品
- **商品搜索**：支持商品搜索（基于Elasticsearch）

### 4.3 购物车模块

- **添加商品**：将商品添加到购物车
- **删除商品**：从购物车中删除商品
- **修改数量**：修改购物车中商品的数量
- **购买商品**：从购物车中购买商品，生成订单

### 4.4 订单模块

- **订单列表**：展示用户的历史订单，支持按状态筛选（全部、待付款、待收货、已完成）
- **订单详情**：展示订单的详细信息
- **订单状态**：支持待付款、待发货、待收货、已完成、已取消等状态
- **订单编号**：自动生成25位唯一订单编号（基于年月日时分秒 + 用户名哈希值 + 随机数）
- **物流信息**：支持查看物流信息
- **确认收货**：支持确认收货
- **取消订单**：支持取消订单
- **申请退款**：支持申请退款

### 4.5 缓存模块

- **Redis缓存**：使用Redis缓存商品、分类和购物车数据
- **缓存过期**：商品和分类缓存10分钟，购物车缓存30分钟
- **容错处理**：当Redis连接失败时，自动降级为直接从数据库查询

### 4.6 短信模块

- **发送验证码**：支持发送短信验证码到用户手机
- **验证验证码**：支持验证用户输入的短信验证码
- **验证码存储**：验证码存储在Redis中，有效期5分钟

## 5. 快速开始

### 5.1 环境要求

- **本地开发环境**：
  - JDK 17+
  - Maven 3.6+
  - Node.js 16+
  - MySQL 8.0+
  - Redis 6.0+
  - Elasticsearch 7.0+（可选）

- **Docker环境**：
  - Docker 20.0+
  - Docker Compose 1.29+

### 5.2 本地开发启动

#### 5.2.1 后端启动

1. **配置数据库**：
   - 创建MySQL数据库 `db_products_0001`
   - 修改 `application.properties` 中的数据库连接配置

2. **配置Redis**：
   - 修改 `application.properties` 中的Redis连接配置

3. **配置阿里云短信API**：
   - 修改 `SmsServiceImpl.java` 中的AccessKey ID和AccessKey Secret

4. **构建和运行**：

```bash
# 构建项目
mvn clean package

# 运行项目
java -jar target/login-backend-1.0-SNAPSHOT.jar
```

#### 5.2.2 前端启动

1. **安装依赖**：

```bash
npm install
```

2. **启动开发服务器**：

```bash
npm run dev
```

3. **构建生产版本**：

```bash
npm run build
```

### 5.3 Docker一键部署

#### 5.3.1 构建和启动

1. **构建后端项目**：

```bash
cd login-backend
mvn clean package
cd ..
```

2. **启动所有服务**：

```bash
docker-compose up -d
```

3. **查看服务状态**：

```bash
docker-compose ps
```

#### 5.3.2 访问服务

- **前端服务**：http://localhost
- **后端服务**：http://localhost:8080
- **MySQL**：localhost:3306
- **Redis**：localhost:6379

#### 5.3.3 停止服务

```bash
docker-compose down
```

#### 5.3.4 环境变量配置

在 `docker-compose.yml` 文件中，可以修改以下环境变量：

- **MySQL**：
  - `MYSQL_ROOT_PASSWORD`：MySQL根密码
  - `MYSQL_DATABASE`：数据库名称

- **后端服务**：
  - `SPRING_DATASOURCE_URL`：数据库连接URL
  - `SPRING_DATASOURCE_USERNAME`：数据库用户名
  - `SPRING_DATASOURCE_PASSWORD`：数据库密码
  - `SPRING_REDIS_HOST`：Redis主机
  - `SPRING_REDIS_PORT`：Redis端口
  - `SPRING_REDIS_PASSWORD`：Redis密码

## 8. 缓存设计

### 8.1 缓存键设计

| 缓存类型 | 缓存键格式 | 过期时间 |
|---------|-----------|---------|
| 商品列表 | products:list | 10分钟 |
| 商品详情 | products:detail:{id} | 10分钟 |
| 分类列表 | categories:list | 10分钟 |
| 分类商品 | categories:products:{categoryId} | 10分钟 |
| 购物车 | cart:{username} | 30分钟 |
| 短信验证码 | sms:verify:{phoneNumber} | 5分钟 |

### 8.2 缓存策略

- **读缓存**：先从缓存中读取数据，如果缓存不存在则从数据库查询并写入缓存
- **写缓存**：修改数据时，同时更新缓存或清除缓存
- **容错处理**：当Redis连接失败时，自动降级为直接从数据库查询

## 9. 安全设计

### 9.1 密码加密

- 使用Spring Security的BCryptPasswordEncoder对密码进行加密存储
- 密码强度要求：包含大小写字母、数字和特殊字符，长度至少8位

### 9.2 CORS配置

- 使用Spring Boot的CORS配置，允许前端跨域请求
- 配置允许的源、方法和头部信息

### 9.3 短信验证码

- 使用阿里云短信API发送验证码
- 验证码存储在Redis中，有效期5分钟
- 防止验证码滥用，设置发送间隔为60秒

## 12. 常见问题

### 12.1 登录失败

- **原因**：用户名或密码错误
- **解决方案**：检查用户名和密码是否正确，或使用忘记密码功能重置密码

### 12.2 注册失败

- **原因**：密码不符合规则、两次密码输入不一致、短信验证码错误
- **解决方案**：确保密码包含大小写字母、数字和特殊字符，长度至少8位；确保两次密码输入一致；确保短信验证码正确

### 12.3 商品分类不显示

- **原因**：分类数据未初始化
- **解决方案**：确保数据库中已创建分类表并插入分类数据

### 12.4 短信验证码发送失败

- **原因**：阿里云短信API配置错误
- **解决方案**：检查AccessKey ID和AccessKey Secret是否正确，确保短信模板和签名已审核通过

### 12.5 Redis连接失败

- **原因**：Redis服务未启动或连接配置错误
- **解决方案**：确保Redis服务已启动，检查Redis连接配置是否正确
